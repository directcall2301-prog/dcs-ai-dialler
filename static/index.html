Simulation rules

  • Lead must not be suppressed.
  • Calling window must be marked approved.
  • TPS screening evidence must be present for UK numbers.
  • Consent type must match the intended call type.
  • Agent availability is displayed, not used to place calls.

These are conservative software gates, not a legal compliance determination. Automated marketing calls require specific consent. Have UK counsel/compliance review the production rules.
